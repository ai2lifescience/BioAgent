# Mock Bakta outputs

These are synthetic examples of the normalized Bakta branch of the
`bacterial_annotation` pipeline. Bakta was not executed to create them. The
annotations, statistics, inference values, and database metadata are fixtures
only and must not be used for scientific interpretation.

At runtime the raw Bakta `.gff3` and `.gbff` files are copied to the stable
BioAgent names `annotation.gff` and `annotation.gbk`. The raw originals remain
available in `annotation_outputs.zip`.
