# BacFunc deployment

Copy this directory alone, create its environment, install it, and connect a separately managed eggNOG v5 directory through YAML or environment variables. Run `bacfunc doctor --config <deployment-config>` before the first sample.

Validate a small control in a new output directory and inspect status, database/version provenance, argument-list commands, retained raw eggNOG and Prokka files, final tables, QC, and separate logs. Database acquisition is deliberately outside this project.
